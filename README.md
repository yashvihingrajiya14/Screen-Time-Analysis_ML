# Screen Time Analysis Using Machine Learning

## 📌 Project Overview

This project analyzes screen-time patterns and uses Machine Learning to classify users into different screen-time categories.

The project includes data preprocessing, exploratory data analysis, model development, and performance evaluation. A **K-Nearest Neighbors (KNN)** classification model was used to predict screen-time categories based on the available input features.

The model achieved approximately **80% accuracy on the test dataset**.

---

## 🎯 Objectives

- Analyze patterns and trends related to screen-time behavior.
- Clean and preprocess the data for Machine Learning.
- Perform exploratory data analysis (EDA).
- Prepare input features and the target variable.
- Build a K-Nearest Neighbors (KNN) classification model.
- Predict screen-time categories.
- Evaluate the performance of the trained model.

## 🔄 Project Workflow

### 1. Data Preprocessing

The data was prepared for Machine Learning by:

- Examining the dataset structure
- Checking for missing values
- Preparing the input features
- Preparing the target variable

### 2. Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to understand screen-time patterns and identify relationships within the data.

The analysis included:

- Studying feature distributions
- Identifying trends and patterns
- Creating visualizations to understand the data

### 3. Data Preparation

The dataset was divided into:

- **Training data** — Used to train the Machine Learning model
- **Testing data** — Used to evaluate the model's performance

### 4. Model Development

A **K-Nearest Neighbors (KNN)** classification model was developed to predict screen-time categories.

KNN predicts the category of a new data point by considering the categories of its nearest neighboring data points.

### 5. Model Evaluation

The trained model was evaluated using the test dataset.

**Approximate Test Accuracy: 80%**

---

## 📊 Results

The KNN classification model achieved approximately **80% accuracy** on the test dataset.

The results demonstrate that Machine Learning can be used to identify patterns in screen-time behavior and classify users based on the available features.
